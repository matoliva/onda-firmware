# Plans

This directory contains proposed or active feature work only.

Before implementation, create `NNN-feature-name.md` with the objective, scope,
requirements, non-goals, validation steps, and completion criteria. Once the
feature is complete and all required validation has passed, rewrite the plan as a
record under `decisions/` and remove the completed plan.

Do not archive hardware-dependent work until it has been validated on the
physical device.
